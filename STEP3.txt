0. On BOTH NODES run this: conda activate megatron 

1. On BOTH NODES set the following environment variables and run small tests

export CUDA_HOME="$CONDA_PREFIX"
export PATH="$CUDA_HOME/bin:$PATH"
export CC=/usr/bin/gcc-11
export CXX=/usr/bin/g++-11
export CUDAHOSTCXX="$CXX"
export MAX_JOBS=2

hostname
echo "SLURM_JOB_ID=$SLURM_JOB_ID"
python -c 'import torch; print(torch.__version__); print(torch.cuda.get_device_name(0))'


2. On NODE 1 ONLY run the following

cd ~
git clone https://github.com/microsoft/Megatron-DeepSpeed.git

3. On NODE 1 ONLY, copy the provided script run_deepspeed_example.sh into the Megatron-DeepSpeed/examples_deepspeed directory. NOTE: there may already be a script by this name there. It is NOT the same. I suggest you archive it rather than deleting it

4. Change the value of workdir in run_deepspeed_example.sh to your working directory path of choice (any empty directory), along with the master_node and worker_node

5. Run the following commands in BOTH terminals

cd Megatron-DeepSpeed/
export PYTHONPATH="$PWD${PYTHONPATH:+:$PYTHONPATH}"
bash examples_deepspeed/run_deepspeed_example.sh
